# SOC/DFIR Platform & Live Cyber Range Workstation

> **Автономная рабочая станция расследования инцидентов (Live SOC/DFIR Workstation) и платформа киберучений (Cyber Range)** на базе высокопроизводительного микроядра Rust и локального интерфейса расследований.

---

## 🚀 О проекте

Платформа спроектирована по принципу **Evidence-Driven Investigation** и **Local First**: все артефакты, процессы, сокеты, сетевые связи и криминалистические данные собираются непосредственно с анализируемой системы и локальной инфраструктуры без синтетических макетов и передачи данных во внешние облака.

### Ключевые возможности

- 🔍 **Live Windows Host Telemetry**: Полный слепок хоста в реальном времени:
  - Дерево процессов с иерархией `Parent-Child`, командными строками и SHA-256 хэшами.
  - Активные сетевые сокеты TCP с привязкой к PID, локальным и удаленным адресам.
  - Точки закрепления (Autorun в реестре Run/RunOnce, Запланированные задачи).
  - Инвентаризация системных служб с детекцией уязвимостей путей (`Unquoted Service Path`).
- 🌐 **Сетевое обнаружение (Network Discovery)**:
  - Парсинг системного кэша ARP и таблицы маршрутизации Windows.
  - Определение активных сетевых интерфейсов, шлюзов по умолчанию и подсетей.
  - Быстрое параллельное TCP-сканирование портов критических сервисов.
- 🛡️ **Инвентаризация ПО и сопоставление с CVE**:
  - Нормализация установленного ПО в стандарты **CPE 2.3** и **Package URL (PURL)**.
  - Локальная база уязвимостей с оценками **CVSS v3**, **EPSS** и флагом **CISA Known Exploited Vulnerabilities (KEV)**.
- ⚡ **Детерминированный движок корреляции**:
  - Потоковая оценка наблюдений (`Observation`) с автоматическим выводом верифицированных фактов (`Fact`).
  - Комплекс правил `CORR-WIN-001` .. `CORR-WIN-004` (дамп LSASS, офисные шеллы, запуск из Temp/Public, подозрительный C2 трафик).
  - Привязка к тактикам/техникам **MITRE ATT&CK** и уровням **Пирамиды боли (Pyramid of Pain)**.
- 📊 **Интерактивный Forensic UI**:
  - Чистый стартовый baseline без учебного шума (`0 моковых находок`).
  - Реактивное наполнение при сборе реальных улик.
  - Инспектор карточек находок (**Drill-Down Inspector**) с детальным техническим обоснованием.
  - Временная шкала расследования (Timeline) и матрица MITRE ATT&CK.
  - Криминалистическое хранилище артефактов с двойным хэшированием (**CAS BLAKE3 + SHA-256**) и реляционная база **SQLite (WAL)**.

## 🏛️ Архитектура платформы

Проект организован в виде модульного Cargo-workspace (`#![forbid(unsafe_code)]` во всех модулях предметной области):

```text
soc-dfir-platform/
├── apps/
│   └── desktop-ui/           # Локальный Forensic UI (HTML5, Vanilla JS, CSS Glassmorphism)
├── crates/
│   ├── core-domain/          # Эпистемическая модель: Fact, Inference, Hypothesis, Observation
│   ├── platform-windows/     # Сбор телеметрии Windows (WinAPI, WMI, реестр, сокеты)
│   ├── platform-linux/       # Сбор телеметрии Linux (/proc, netlink, sysfs)
│   ├── privilege-broker/     # Безопасный брокер привилегированных вызовов
│   ├── normalization-engine/ # Парсинг EVTX/PCAP, генерация CPE 2.3/PURL, сопоставление CVE
│   ├── correlation-engine/   # Детерминированный корреляционный движок и правила находок
│   ├── graph-engine/         # Граф атак и взаимосвязей сущностей
│   ├── timeline-engine/      # Временные дорожки событий и артефактов
│   ├── storage-cas/          # Контентно-адресуемое хранилище артефактов (BLAKE3)
│   ├── storage-sqlite/       # Реляционное хранилище расследований (19 таблиц SQLite WAL)
│   ├── ipc-protocol/         # JSON-RPC 2.0 протокол взаимодействия UI и движка
│   ├── engine-server/        # Фоновый сервис ядра расследований и диспетчер IPC
│   └── desktop-app/          # Нативный десктопный бинарник (WebView2)
└── docs/                     # Детальная инженерная документация
```

## ⚡ Быстрый старт

### Требования
- **ОС**: Windows 10/11 x64 / Windows Server 2019+
- **Rust**: версия 1.85+ (stable)
- **Node.js**: v20+ (для локальной разработки UI)

### Сборка и запуск тестов

```powershell
# Клонирование репозитория
git clone https://github.com/Sirojiddin6556/soc-dfir-platform.git
cd soc-dfir-platform

# Запуск полного набора автоматических тестов
cargo test --workspace

# Проверка линтером clippy
cargo clippy --workspace --all-targets -- -D warnings
```

### Запуск десктопного приложения

```powershell
# Сборка оптимизированного релиза
cargo build --release

# Запуск приложения
.\target\release\desktop-app.exe
```

После запуска откроется окно **Forensic Cockpit** с подключением к локальному движку по IPC.
